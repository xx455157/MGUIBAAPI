**中文名稱：** 發票字軌檔

**最後更新日期：** 2024-07-05
**版本：** 1.0

## 資料表說明

發票字軌檔(B32)用於管理系統中的發票字軌資訊，包含發票的起始與截止號碼、使用狀態、年月範圍等資訊。此資料表提供發票開立時的字軌與號碼分配，並追蹤發票使用情況，支援一般與電子發票的管理，以及總分支機構的配號作業。

## 資料關聯

### 資料表間關聯

- 與[B31_發票主檔](./B31.md)的關聯:

  - B3201 = B31.B3101 (公司別)
  - B3202+B3203 = B31.B3103的前3碼 (字軌組別)
  - 關聯類型: 一對多 (一筆字軌資料可對應多筆發票記錄)
- 與公司資料表的關聯:

  - B3201 = A01.A0101 (公司別)
  - 關聯類型: 多對一 (多筆字軌資料對應一家公司)

### 參照完整性約束

1. 公司別(B3201)必須存在於公司基本資料檔(A01)中
2. 新增發票記錄時，其字軌必須存在於B32表中且狀態(B3210)為"使用中"
3. 發票號碼必須在起始號碼(B3204)和截止號碼(B3205)的範圍內
4. 使用的發票日期必須在起始年月(B3206)和截止年月(B3207)的範圍內

## 資料表特性與管理

1. **發票字軌管理**：

   - 字軌資料建立後，系統自動依序使用發票號碼
   - 當發票號碼使用到截止號碼時，狀態自動更新為"用完"
   - 可同時管理多組發票字軌，依使用需求設定不同組別
2. **發票配號機制**：

   - 支援總分支機構發票號碼配置機制
   - 透過B3216和B3217欄位控制發票號碼配發範圍
   - 可按部門別(B3223)進行發票號碼分配
3. **電子發票支援**：

   - 透過發票性質(B3213)區分一般和電子發票
   - 電子發票和一般發票使用不同的字軌處理規則
4. **前台整合**：

   - 前台系統可透過收銀機編號(B3212)和館別代號(B3224)關聯
   - 使用前台已取發票註記(B3214)防止重複或錯誤使用
