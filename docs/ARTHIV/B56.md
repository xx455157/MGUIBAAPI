# B56_發票主檔

## 資料表資訊

**資料表代碼：** B56  
**中文名稱：** 發票主檔  
**主鍵：** B5601 + B5602 + B5603  
**最後更新日期：** 2024-01-01  
**版本：** 1.0

## 資料表說明

發票主檔(B56)用於記錄發票相關資訊，包含建檔、更改記錄、公司別、發票日期、發票號碼、發票格式、統一編號、銷售金額、課稅別、娛樂稅等資訊。

## 資料型態規範

### 字元型態
- 所有字元欄位統一使用 NVARCHAR 型態，以支援多語言字元
- 代碼類欄位使用 NVARCHAR(n)，長度根據實際需求設定

### 日期型態
- 所有日期欄位統一使用 NVARCHAR(8) 存放
- 日期格式統一為 YYYYMMDD，例如：20240408 表示 2024年4月8日
- 備註欄中標注格式為 (YYYYMMDD)

### 數值型態
- 所有數值欄位統一使用 NUMERIC(25,4) 型態
- 可存儲21位整數和4位小數
- 金額單位統一為「元」，含小數點後4位
