# SINI_系統環境參數設定檔

## 資料表資訊

**系統：** ARTHIV (庫存與訂單管理系統)
**資料表代碼：** SINI
**中文名稱：** 系統環境參數設定檔
**主鍵：** SECTION + TOPIC
**最後更新日期：** 2024-07-02
**版本：** 1.1

## 資料表說明

SINI表為系統環境參數設定檔，用於存儲各種系統設定參數、代碼表和參照資料。該表使用鍵值對的方式存儲配置資訊，透過SECTION和TOPIC的組合作為鍵，TOPICVALUE作為值。系統中各模組通過讀取SINI表中的參數來獲取相關設定。

## 欄位定義

| 欄位代碼   | 欄位名稱 | 資料類型 | 長度 | 屬性 | 備註說明                               |
| ---------- | -------- | -------- | ---- | ---- | -------------------------------------- |
| SECTION    | 參數區塊 | TEXT     | 50   | P,M  | 參數類別，用於分類系統不同功能區的設定 |
| TOPIC      | 參數主題 | TEXT     | 50   | P,M  | 參數名稱，與SECTION組合作為唯一鍵      |
| TOPICVALUE | 參數值   | TEXT     | 50   |      | 存儲參數的實際值                       |

## 索引定義

| 索引名稱    | 索引欄位        | 索引類型 | 用途說明                 |
| ----------- | --------------- | -------- | ------------------------ |
| PK_SINI     | SECTION + TOPIC | 主鍵     | 確保每個參數設定的唯一性 |
| IDX_SINI_01 | SECTION         | 一般     | 加快按參數區塊查詢的速度 |

## 使用方式

系統透過以下幾種方式使用SINI表中的設定：

1. **代碼對照表**：

   - 將特定領域的代碼和其對應說明存儲在同一SECTION下
   - 例如：發票類別、交易類型、單位等
2. **系統參數設定**：

   - 存儲系統運行所需的各種參數
   - 例如：預設值、稅率、計算方式等
3. **使用者偏好設定**：

   - 存儲使用者自定義的系統偏好設定
   - 例如：顯示格式、預設篩選條件等
4. **跨模組參照**：

   - B04庫存異動檔中的發票類別(B0449)參照SINI表中的InvoiceType設定
   - B04庫存異動檔中的異動別(B0410)參照B30異動原因檔進行詳細說明
   - B31發票主檔中的扣抵代號(B3109)參照SINI表中的POTAXDeductType設定

## 資料關聯

SINI表與其他表格的關聯：

1. **與B04庫存異動檔的關聯**：

   - B04.B0449 (發票類別) 參照 SINI.TOPICVALUE (WHERE SECTION='InvoiceType')
   - B04表中多個代碼欄位都參照SINI表中的對應設定
2. **與B30異動原因檔的關聯**：

   - B30.B3002 (異動別) 對應 SINI表中的TXTYPE設定
   - B30表記錄異動原因的詳細說明，SINI表存儲基本代碼對照
3. **與B31發票主檔的關聯**：

   - B31.B3104 (發票格式) 參照 SINI.TOPICVALUE (WHERE SECTION='INVOICESET')
   - B31.B3109 (扣抵代號) 參照 SINI.TOPICVALUE (WHERE SECTION='POTAXDeductType')

## 表格特性與管理

1. **集中式配置管理**：

   - SINI表集中存儲系統所有可配置參數，便於統一管理
   - 系統管理員可透過專用介面修改設定，無需直接修改程式碼
2. **動態載入機制**：

   - 系統啟動或特定操作時動態載入SINI設定
   - 部分設定修改後立即生效，無需重啟系統
3. **參數分類與維護**：

   - 按功能區域使用不同SECTION進行分類
   - 相關參數集中在同一SECTION下，便於維護和查詢
