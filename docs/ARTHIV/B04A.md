# B04A_發票明細異動檔

## 資料表資訊

**系統：** ARTHIV (發票管理系統)
**資料表代碼：** B04A
**中文名稱：** 發票明細異動檔
**主鍵：** B0444 + B0410 + B0411 + B0412 + B0414
**最後更新日期：** 2024-07-17
**版本：** 1.0

## 資料表說明

本資料表用於記錄發票明細異動資料，包含各類異動（如進貨、銷貨、訂單等）之明細資訊，並追蹤異動別、單據號碼、序號、公司別等關鍵欄位。適用於發票管理、稽核及報表分析等場景。

B04A為發票明細異動的主檔，記錄所有異動明細資料，供發票管理、稽核、報表等功能查詢與追蹤。
