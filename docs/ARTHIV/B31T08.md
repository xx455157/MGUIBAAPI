# B31T08_發票內容摘要檔

## 資料表資訊

**系統：** [ARTHIV](../ARTHIV.md) (庫存與訂單管理系統)
**資料表代碼：** B31T08
**中文名稱：** 發票內容摘要檔
**主鍵：** B3101 + B3103 + B3104
**最後更新日期：** 2024-07-11
**版本：** 1.0

## 資料表說明

發票內容摘要檔(B31T08)用於記錄發票的內容摘要資訊，包括摘要名稱、數量及用途說明等。此表與發票主檔(B31)關聯，提供發票內容的詳細摘要資訊。

## 資料關聯說明

### 資料表間關聯

- 與[B31_發票主檔](./B31.md)的關聯:
  - B3101 = B31.B3101 (公司別)
  - B3103 = B31.B3103 (發票號碼)
  - B3104 = B31.B3104 (發票格式)
  - 關聯類型: 多對一 (一張發票可以有多筆內容摘要記錄)

### 參照完整性約束

1. B31T08表的主鍵(B3101+B3103+B3104)必須存在於B31發票主檔表中
2. 新增B31T08記錄時，必須確保對應的B31記錄已存在

## 資料表管理流程

B31T08是ARTHIV系統的發票內容摘要檔，主要記錄各發票的內容摘要說明、數量及用途等資訊，用以補充發票主檔的詳細內容。
