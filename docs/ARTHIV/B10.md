# B10產品主檔

## 資料表資訊

**系統：** [ARTHIV](../ARTHIV.md) (金旭庫存管理系統)
**資料表代碼：** B10
**中文名稱：** 產品主檔 (原ＩＭ)
**主鍵：** B1001+B1002
**最後更新日期：** 2024-07-05
**版本：** 1.1

## 資料表說明

產品主檔用於記錄庫存產品的基本資料，包含產品類別、單位、價格、成本、庫存數量等資訊。
(Trigger 串.Net)

## 產品別代碼說明


| 代碼  | 說明  | 詳細說明           |
| --- | --- | -------------- |
| 1   | 商品  | 供銷售用的商品        |
| 2   | 原料  | 製造過程中使用的原料     |
| 3   | 物料  | 各類輔助性物料        |
| 4   | 在製品 | 尚在製作過程中的產品     |
| 5   | 半成品 | 製作完成但未達成品階段的產品 |
| 6   | 製成品 | 完全製作完成的產品      |
| 7   | 費用  | 與產品相關的費用項目     |
| 8   | 資產  | 列入資產的產品項目      |
