## 資料表說明

電子發票平台介接記錄檔(B31A)專門用於記錄Turnkey程式上傳至電子發票平台的資料傳輸狀態與平台回傳的訊息。本資料表追蹤電子發票從系統產生、上傳至平台、到平台回傳處理結果的完整生命週期，包括開立及作廢的處理狀態、時間戳記及錯誤訊息等，為電子發票與平台介接過程提供完整的稽核軌跡。

## 資料關聯

### 資料表間關聯

- 與[B31_發票主檔](./B31.md)的關聯:
  - B31A01 = B31.B3101 (公司別)
  - B31A02 = B31.B3102 (發票日期)
  - B31A03 = B31.B3103 (發票號碼)
  - B31A04 = B31.B3104 (發票格式)
  - 關聯類型: 一對一 (一筆電子發票平台介接記錄對應一筆發票主檔記錄)

### 參照完整性約束

1. B31A表的主鍵(B31A01+B31A02+B31A03+B31A04)必須存在於B31表中
2. 當B31A05='1'時，必須確保對應的發票主檔記錄存在
3. 資料來源(B31A05)必須為有效的代碼值(1或2)
4. 發票格式(B31A04)必須參照SINI表中SECTION='INVOICESET'的有效代碼

## 資料表特性與管理

1. **Turnkey電子發票介接機制**：

   - 本表專門記錄Turnkey程式與電子發票平台之間的交互作業
   - Turnkey程式負責將系統產生的電子發票資料上傳至政府電子發票平台
   - 記錄平台回傳的處理結果，提供發票開立及作廢狀態追蹤
2. **電子發票處理生命週期**：

   - 電子發票開立流程：系統產生發票 → Turnkey上傳至平台(B31A08) → 平台處理 → Turnkey接收回傳(B31A09)
   - 電子發票作廢流程：系統標記作廢 → Turnkey上傳至平台(B31A10) → 平台處理 → Turnkey接收回傳(B31A11)
   - 每個流程階段的執行時間和處理結果均有記錄
3. **錯誤處理及監控**：

   - 透過B31A06及B31A07欄位監控平台處理狀態
   - 若處理失敗，B31A27欄位記錄詳細的錯誤訊息
   - 系統管理人員可透過本表進行電子發票傳輸問題的診斷和排除
4. **資料審計與稽核**：

   - 提供電子發票完整的傳輸稽核軌跡
   - 可追蹤每張發票在平台處理的時間和結果
   - 支援電子發票相關報表和稽核作業
