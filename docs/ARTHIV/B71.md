# B71\_組合單主檔

## 資料表資訊

**系統：** [ARTHIV](../ARTHIV.md) (庫存與訂單管理系統)
**資料表代碼：** B71
**中文名稱：** 組合單主檔
**主鍵：** B7101+B7102
**最後更新日期：** 2024-12-01
**版本：** 1.0

## 資料表說明

組合單主檔(B71)是 ARTHIV 系統中用於記錄組合單主要資料的表格。此表主要用於管理產品組合的基本資訊，包括組合單號、主件產品編號、組合工時等相關資料，為組合單管理提供主要的追蹤記錄。

## 資料關聯說明

### 資料表間關聯

- 與公司基本資料檔(A01)的關聯:

  - B7101 = A0101 (公司別)
  - 關聯類型: 多對一 (公司基本資料檔對應多筆組合單主檔)

- 與產品基本資料檔(B01)的關聯:

  - B7103 = B0101 (產品編號)
  - 關聯類型: 多對一 (產品基本資料檔對應多筆組合單主檔)

- 與組合單明細檔(B71A)的關聯:
  - B7101 = B71A01 (公司別)
  - B7102 = B71A02 (組合單號)
  - 關聯類型: 一對多 (組合單主檔對應多筆明細檔)

### 參照完整性約束

1. 公司別(B7101)必須存在於公司基本資料檔(A01)中
2. 主件產品編號(B7103)必須存在於產品基本資料檔(B01)中
