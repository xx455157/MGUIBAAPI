# B27_產品庫存月結檔

## 資料表資訊

**系統：** [ARTHIV](../ARTHIV.md) (金旭庫存管理系統)
**資料表代碼：** B27
**中文名稱：** 產品庫存月結檔
**主鍵：** B2701+B2702+B2703
**最後更新日期：** 2024-07-11
**版本：** 1.0

## 資料表說明

產品庫存月結檔(B27)用於記錄系統中各產品每月期末的庫存數量、金額及成本資訊，作為庫存管理和財務報表的基礎資料。

## 資料關聯說明

### 資料表間關聯

- 與[ARTHGUI-A01公司基本資料檔](../ARTHGUI/A01.md)的關聯:

  - B2701 = A01.A0101 (公司別)
  - 關聯類型: 多對一 (多筆庫存記錄對應一個公司)
- 與[產品主檔]的關聯:

  - B2701+B2702 = 產品主檔.公司別+產品編號
  - 關聯類型: 多對一 (多筆庫存記錄對應一個產品)

### 參照完整性約束

1. 新增庫存月結記錄時，B2701+B2702組合必須在產品主檔中存在
2. 特定公司別和產品編號在同一年月不得有重複記錄

## 資料表管理流程

產品庫存月結檔(B27)是金旭庫存管理系統的重要資料表，記錄各產品每月庫存結餘情況。系統在每月結帳時，自動彙總庫存交易資料並產生月結記錄，提供管理者查詢歷史庫存及成本變化趨勢。
