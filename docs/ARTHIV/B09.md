# B09產品類別檔

## 資料表資訊

**系統：** ARTHIV (庫存與訂單管理系統)
**資料表代碼：** B09
**中文名稱：** 產品類別檔
**主鍵：** B0901+B0902+B0903
**最後更新日期：** 2024-12-19
**版本：** 1.0

## 資料表說明

產品類別檔(B09)是 ARTHIV 系統中定義產品分類結構的主檔，記錄各公司產品的基本分類資訊。此表用於建立產品的分類體系，支援產品管理、報表統計、庫存分析等功能。每個產品類別包含類別編號、說明、存貨科目等關鍵資訊，為系統提供完整的產品分類架構。

## 代碼說明

### 零庫存品標記 (B0906)


| 代碼  | 說明   | 詳細說明             |
| --- | ---- | ---------------- |
| Y   | 零庫存品 | 該產品為零庫存管理模式      |
| ''  | 一般庫存 | 該產品為一般庫存管理模式(預設) |


### 列入庫存標記 (B0907)


| 代碼  | 說明   | 詳細說明         |
| --- | ---- | ------------ |
| Y   | 列入庫存 | 該產品類別需列入庫存管理 |
| ''  | 不列入  | 該產品類別不列入庫存管理 |


## 資料關聯說明

### 資料表間關聯

- 與 B10(產品主檔)的關聯:
  - B0902 = B10.產品編號
  - 關聯類型: 多對一 (多筆產品類別對應一個產品)
- 與 B04(庫存異動檔)的關聯:
  - B0902 = B04.產品編號
  - 關聯類型: 多對一 (多筆庫存異動對應一個產品類別)
- 與 A01(公司基本資料檔)的關聯:
  - B0901 = A01.公司代碼
  - 關聯類型: 多對一 (多筆產品類別對應一個公司)

### 參照完整性約束

1. 公司別(B0901)必須存在於公司基本資料檔(A01)中
2. 產品編號(B0902)必須存在於產品主檔(B10)中
3. 存貨科目(B0914)必須符合會計科目編碼規範
