## 資料表資訊

**系統：** [ARTHIV](../ARTHIV.md) (庫存與訂單管理系統)
**資料表代碼：** B31
**中文名稱：** 發票主檔
**主鍵：** B3101 + B3102 + B3103 + B3104
**最後更新日期：** 2024-07-05
**版本：** 1.3

## 資料表說明

發票主檔(B31)用於記錄系統中所有發票相關資訊，包括進項發票、銷項發票、折讓單等各種類型。此表儲存了發票的基本資料、金額、稅額、狀態等完整資訊，是系統中進銷項發票管理的核心資料表。

## 資料關聯

### 資料表間關聯

- 與[B04_庫存異動檔](./B04.md)的關聯:

  - B3104 = B04.B0449 (發票類別)
  - B3103 = B04.B0436 (發票號碼)
  - 關聯類型: 一對多 (一個發票對應多筆庫存異動記錄)
- 與[B30_異動原因檔](../ARTHGUI/B30.md)的關聯:

  - B3113 = B30.B3002 (異動別)
  - 關聯類型: 多對一 (多筆發票記錄對應一個異動原因)
- 與[SINI_系統環境參數設定檔](./SINI.md)的關聯:

  - B3104 參照 SINI.TOPICVALUE (WHERE SECTION='INVOICESET')
  - B3109 參照 SINI.TOPICVALUE (WHERE SECTION='POTAXDeductType')
  - 關聯類型: 多對一 (多筆發票記錄對應到SINI表中的代碼)

### 參照完整性約束

1. B04表中的B0449欄位值必須符合B3104欄位定義的發票格式
2. 若發票狀態為作廢(B3112='2')，則相關的庫存異動記錄需特別處理
3. 電子發票(B3139='2')需填寫完整的電子發票相關欄位
4. B3104欄位值必須參照SINI表中SECTION='INVOICESET'的有效代碼
5. B3109欄位值必須參照SINI表中SECTION='POTAXDeductType'的有效代碼

`<a id="table-characteristics"></a>`

## 資料表特性與管理

1. **發票維護說明**：

   - 本表主要由系統自動寫入，使用者可透過發票作業畫面查詢或修改
   - 發票一旦開立，除特殊狀況外不建議直接修改
   - 作廢發票需記錄作廢原因及日期時間
2. **報表相關**：

   - 營業稅申報資料來源
   - 銷售分析報表資料來源
   - 進銷貨明細表資料來源
