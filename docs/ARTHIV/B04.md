# B04\_庫存異動檔

## 資料表資訊

**系統：** ARTHIV (庫存與訂單管理系統)
**表格代碼：** B04
**中文名稱：** 庫存異動檔
**主鍵：** B0444+B0410+B0411+B0412+B0414
**最後更新日期：** 2024-07-02
**版本：** 1.1

## 資料表說明

庫存異動檔(B04)是 ARTHIV 系統中的核心表格，記錄所有影響庫存的交易動作，包括採購、銷售、調撥、組合、盤點等操作。每一筆異動記錄都包含完整的異動信息，如產品代碼、數量、成本、異動日期等，為庫存管理提供詳細的追蹤記錄。

## 資料關聯說明

### 表格間關聯

- 與 B10(產品主檔)的關聯:

  - B0401 = B10.產品編號
  - 關聯類型: 多對一 (多筆庫存異動對應一個產品)

- 與 B06(訂單主檔)的關聯:

  - B0425 = B06.訂單編號 (銷貨時)
  - 關聯類型: 多對一 (多筆庫存異動對應一個訂單)

- 與 B25(採購主檔)的關聯:

  - B0425 = B25.採購單號 (採購時)
  - 關聯類型: 多對一 (多筆庫存異動對應一個採購單)

- 與 B14(產品庫存明細檔)的關聯:

  - B0401+B0417+B0444 = B14.產品代碼+B14.庫別+B14.公司別
  - 關聯類型: 多對一 (多筆庫存異動影響一筆庫存記錄)

- 與 B31(發票主檔)的關聯:

  - 關聯類型: 多對一 (多筆庫存異動明細對應一筆發票主檔)
  - B0444=B3101(公司別)
  - B0414=B3102(發票日期)
  - B0436=B3103 (發票號碼)
  - B0449=B3104 (發票類別)

### 參照完整性約束

1. 產品編號(B0401)必須存在於產品主檔(B10)中
2. 庫別(B0417 與 B0418)必須存在於庫別代碼表中
3. 發票號碼(B0436)必須符合發票號碼格式規範
4. 當異動別(B0410)為組合相關時，源產品與目標產品必須遵循組合規則

## 表格管理流程

庫存異動檔(B04)是 ARTHIV 進銷存系統的核心表格，記錄所有與庫存變動相關的交易。系統中的採購、銷售、調撥、組合拆解等操作都會在此表中產生相應的記錄。
