## 索引說明
- 主鍵索引：B0801 + B0802 + B0803 + B0804

## 備註
1. 本資料表用於記錄庫存管理系統中的各種檔案關聯資訊
2. 類別代碼(B0802)用於區分不同類型的檔案關聯
3. 序號(B0804)用於區分同一類別下的不同記錄
4. 羅森交期備註：B0801(公司別) + B0802(IED) + B0803(單號) + B0810(序號) + B0813(產品編號)
