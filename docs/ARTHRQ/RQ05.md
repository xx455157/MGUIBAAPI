# RQ05\_請購簽核紀錄

## 資料表資訊

**系統：** ARTHRQ (請購系統)  
**資料表代碼：** RQ05  
**中文名稱：** 請購簽核紀錄  
**主鍵：** RQ0501 + RQ0502 + RQ0503  
**最後更新日期：** 2024-01-01  
**版本：** 1.0

## 資料表說明

請購簽核紀錄(RQ05)用於記錄請購單的簽核流程資訊，包含建檔、更改記錄、公司別、請購單號、簽核順序序號、目前核准人、簽核結果、簽核日期、備註等資訊。

## 資料關聯說明

### 資料表間關聯

- 與公司基本資料檔(RQ01)的關聯:

  - RQ0501 = RQ01.RQ0101
  - 關聯類型: 多對一 (多個簽核記錄對應一個公司)

- 與請購主檔(RQ02)的關聯:
  - RQ0502 = RQ02.RQ0202
  - 關聯類型: 多對一 (多個簽核記錄對應一個請購單)
