# RQ01_部門主管

## 資料表資訊

**系統：** [ARTHRQ](../ARTHRQ.md) (金旭請購系統)  
**資料表代碼：** RQ01  
**中文名稱：** 部門主管  
**主鍵：** RQ0106 + RQ0101  
**最後更新日期：** 2026-05-21  
**版本：** 1.0

## 資料表說明

部門主管檔(RQ01)用於記錄各公司、各部門的主管資訊，為簽核流程管理模組的基礎設定檔。此表與部門標準簽核程序檔(RQ02)搭配使用，作為請購簽核流程的起始參照資料。

## 資料關聯說明

### 資料表間關聯

- 與[RQ02_部門標準簽核程序](./RQ02.md)的關聯:

  - RQ0106 = RQ02.RQ0201 (公司別)
  - RQ0101 = RQ02.RQ0204 (部門編號)
  - 關聯類型: 一對多 (一筆部門主管設定可對應多筆簽核程序)

### 參照完整性約束

1. 公司別(RQ0106)必須存在於公司基本資料檔中
2. 部門別(RQ0101)必須存在於部門資料檔中
3. 部門主管編號(RQ0102)必須存在於員工基本資料檔中
