# RQ04A_請購明細延伸檔

## 資料表資訊

**系統：** ARTHRQ (請購系統)  
**資料表代碼：** RQ04A  
**中文名稱：** 請購明細延伸檔  
**主鍵：** RQ04A01 + RQ04A02 + RQ04A03  
**最後更新日期：** 2024-01-01  
**版本：** 1.0

## 資料表說明

請購明細延伸檔(RQ04A)用於記錄六福皇宮.NET聯合請購的相關資訊，包含建檔、更改記錄、公司別、請購單號、序號、統購資訊、收貨資訊、訂單類型等資料。

## 資料關聯說明

### 資料表間關聯

- 與公司基本資料檔(RQ01)的關聯:
  - RQ04A1 = RQ01.RQ0101
  - 關聯類型: 多對一 (多個請購明細延伸記錄對應一個公司)

- 與請購主檔(RQ02)的關聯:
  - RQ04A2 = RQ02.RQ0202
  - 關聯類型: 多對一 (多個請購明細延伸記錄對應一個請購單)
