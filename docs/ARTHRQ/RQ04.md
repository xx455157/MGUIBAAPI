# RQ04_請購明細檔

## 資料表資訊

**系統：** [ARTHRQ](../ARTHRQ.md) (金旭請購系統)  
**資料表代碼：** RQ04  
**中文名稱：** 請購明細檔  
**主鍵：** RQ0401 + RQ0402 + RQ0403  
**最後更新日期：** 2024-07-17  
**版本：** 1.0

## 資料表說明

請購明細檔(RQ04)用於記錄請購單的明細資料，包含請購項目、數量、金額、簽核狀態等資訊。此表是請購系統的核心資料表之一，與請購單主檔(RQ01)和請購單簽核檔(RQ02)密切相關。

## 資料關聯說明

### 資料表間關聯

- 與請購單主檔(RQ01)的關聯：
  - RQ0401+RQ0402 = RQ01.RQ0101+RQ0102
  - 關聯類型：多對一 (多筆請購明細對應一張請購單)

- 與請購單簽核檔(RQ02)的關聯：
  - RQ0401+RQ0402 = RQ02.RQ0201+RQ0202
  - 關聯類型：多對一 (多筆請購明細對應一筆簽核記錄)

### 參照完整性約束

1. 公司別(RQ0401)必須存在於公司基本資料檔(A01)中
2. 請購單號(RQ0402)必須存在於請購單主檔(RQ01)中
3. 請購部門(RQ0407)必須存在於部門資料檔(A02)中
4. 請購員工代號(RQ0408)必須存在於員工基本資料檔(A08)中

## 資料表特性說明

1. **六福皇宮專用欄位**：
   - RQ0409 (請購日期)：用於記錄申請日
   - RQ0413 (參考憑證)：使用15碼請購單號
   - RQ0416 (預定取得日期)：用於記錄需求日
   - RQ0437 (Filler)：用於記錄到貨日
   - RQ0438 (Filler)：用於記錄預計入帳日
   - RQ0430 (品項說明2)：用於記錄英文品名
   - RQ0442 (指示量)：用於記錄調入量

2. **請購性質代碼**：
   - 1：資產
   - 2：費用
   - 3：存貨
   (資料來源：SINI, Section=RQ_Type)

3. **請購現況代碼**：
   - 0：未處理
   - 1：簽核中
   - 2：採購中
   - 3：結案
   - 4：取消

4. **簽核現況代碼**：
   - 1：未處理
   - 2：簽核中
   - 3：退回
   - 4：已核准
   - 5：照會
