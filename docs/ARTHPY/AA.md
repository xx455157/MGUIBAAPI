## 資料表說明

`<a id="table-description"></a>`

考勤記錄檔(AA)主要用於記錄人事薪資系統中員工的考勤資料，包括請假、加班等各種出勤異動紀錄。此表格作為薪資計算的基礎數據來源，記錄員工的出勤情況以及相關計算數據。

## 資料型態規範

`<a id="data-type-standards"></a>`

### 字元型態

- 所有字元欄位統一使用 NVARCHAR 型態，以支援多語言字元
- 禁止使用TEXT型態，所有TEXT型態需全部改為NVARCHAR(n)，長度根據實際需求設定
- 代碼類欄位使用 NVARCHAR(n)，長度根據實際需求設定

### 日期型態

- 所有日期欄位統一使用 NVARCHAR(8) 存放
- 日期格式統一為 YYYYMMDD，例如：20240408 表示 2024年4月8日

### 數值型態

- 所有數值欄位統一使用 NUMERIC(25,4) 型態
- 可存儲21位整數和4位小數
- 金額單位統一為「元」，含小數點後4位

## 資料關聯說明

`<a id="data-relations"></a>`

### 資料表間關聯

- 與考勤異動代碼檔(AB)的關聯:
  - AA05 = AB03 (異動代號)
  - AA13 = AB01 (考勤類別)
  - 關聯類型: 多對一 (多筆考勤記錄可能使用同一個異動代碼)
- 與員工基本資料檔(AE)的關聯:
  - AA01 = AE01 (公司別)
  - AA03 = AE03 (身份證字號)
  - 關聯類型: 多對一 (一個員工可能有多筆考勤記錄)
- 與薪資計算資料檔(AD)的關聯:
  - AA01, AA03, AA05 -> AD相關欄位
  - 關聯類型: 一對多 (考勤記錄會產生多筆薪資計算數據)

### 參照完整性約束

1. 公司別(AA01)必須存在於公司基本資料檔(A01)中
2. 異動代號(AA05)必須存在於考勤異動代碼檔(AB)中
3. 員工身份證字號(AA03)必須存在於員工基本資料檔(AE)中
4. 異動代號與扣抵異動代號的對應必須符合AB表中的定義

## 資料表管理流程

`<a id="management-process"></a>`

考勤記錄檔(AA)是薪資系統的核心資料表，負責記錄所有員工的出勤、請假、加班等考勤資料。這些資料將作為薪資計算的基礎，影響薪資發放的準確性與合規性。
