# PB_發薪記錄檔

## 資料表資訊

**系統：** [ARTHPY](../ARTHPY.md) (薪資系統)
**資料表代碼：** PB
**中文名稱：** 發薪記錄檔
**主鍵：** PB02+PB04+PB07+PB08+PB09+PB12+PB13
**最後更新日期：** 2024-07-17
**版本：** 1.0

## 資料表說明

發薪記錄檔(PB)用於記錄員工薪資發放相關資訊，包含薪資項目、金額、所得類別等資料，作為薪資發放與稅務申報的依據。

## 資料關聯說明

### 資料表間關聯

- 與[ARTHGUI-A01公司基本資料檔](../ARTHGUI/A01.md)的關聯：

  - PB02 = A01.A0101 (公司別)
  - 關聯類型：多對一 (多筆薪資記錄對應一個公司)
- 與[ARTHGUI-A02部門基本資料檔](../ARTHGUI/A02.md)的關聯：

  - PB03 = A02.O001 (部門別)
  - 關聯類型：多對一 (多筆薪資記錄對應一個部門)
- 與[ARTHPY-A08員工基本資料檔](./A08.md)的關聯：

  - PB05 = A08.A0801 (員工代號)
  - 關聯類型：多對一 (多筆薪資記錄對應一個員工)

### 參照完整性約束

1. 公司別(PB02)必須存在於公司基本資料檔(A01)中
2. 部門別(PB03)必須存在於部門基本資料檔(A02)中
3. 員工代號(PB05)必須存在於員工基本資料檔(A08)中

## 資料表管理流程

發薪記錄檔(PB)是薪資系統的核心資料表，用於記錄所有員工的薪資發放資訊。系統在計算薪資時會產生此表的記錄，並作為後續稅務申報、勞健保計算等作業的依據。
