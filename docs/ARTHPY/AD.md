# AD_加班倍數設定檔

## 資料表資訊

**系統：** [ARTHPY](../ARTHPY.md) (薪資系統)  
**資料表代碼：** AD  
**中文名稱：** 加班倍數設定檔  
**主鍵：** AD01  
**最後更新日期：** 2026-05-21  
**版本：** 1.0

## 資料表說明

加班倍數設定檔(AD)用於定義各加班代號的計算倍數及是否免稅等參數，作為考勤與薪資計算時加班費換算的基礎設定。此表與考勤異動代碼檔(AB)、考勤記錄檔(AA)搭配使用。

## 免稅代碼說明 (AD03)

| 代碼 | 說明 | 詳細說明         |
| ---- | ---- | ---------------- |
| Y    | 免稅 | 此加班類別免稅   |
| N    | 應稅 | 此加班類別需課稅 |

## 資料關聯說明

### 資料表間關聯

- 與[AB_考勤異動代碼檔](./AB.md)的關聯:

  - 加班相關異動代碼計算時參照本表倍數設定
  - 關聯類型: 設定參照 (異動代碼與加班代號於業務邏輯中對應使用)

- 與[AA_考勤記錄檔](./AA.md)的關聯:

  - 考勤加班異動計算加班費時引用 AD02 加班倍數
  - 關聯類型: 設定參照

### 參照完整性約束

1. AD01 加班代號不可重複
2. AD02 加班倍數須為有效數值且大於 0
3. AD03 若填寫須為 Y 或 N
