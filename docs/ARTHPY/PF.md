# PF_員工基本支薪檔

## 資料表資訊

**系統：** ARTHPY (人力資源管理系統)  
**資料表代碼：** PF  
**中文名稱：** 員工基本支薪檔  
**主鍵：** PF01+PF04+PF03+PF05 (P & U)  
**最後更新日期：** 2024-01-01  
**版本：** 1.0

## 資料表說明

員工基本支薪檔用於記錄員工的支薪資訊，包括支薪代碼、支薪金額、調薪前金額等薪資相關資料。此表記錄員工的基本薪資信息，支援調薪處理功能。

## 資料關聯說明

### 資料表間關聯

- 與公司別主檔的關聯:
  - PF01 = 公司別主檔.公司代碼
  - 關聯類型: 多對一 (多筆支薪記錄對應一個公司)

- 與部門別主檔的關聯:
  - PF02 = 部門別主檔.部門代碼
  - 關聯類型: 多對一 (多筆支薪記錄對應一個部門)

- 與員工基本資料的關聯:
  - PF04 = 員工基本資料.身份證字號
  - 關聯類型: 多對一 (多筆支薪記錄對應一個員工)

### 參照完整性約束

1. PF01 必須參照公司別主檔
2. PF02 必須參照部門別主檔  
3. PF04 必須參照員工基本資料
4. 主鍵組合 (PF01+PF04+PF03+PF05) 必須唯一

## 資料表管理流程

員工基本支薪檔是人力資源管理系統的核心資料表，記錄員工的基本支薪資訊。支援調薪處理功能，系統會記錄調薪前後的金額差異，並記錄調薪處理日期。
