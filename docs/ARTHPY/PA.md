# PA_員工基本檔

## 資料表資訊

**系統：** [ARTHPY](../ARTHPY.md) (人力資源管理系統)  
**資料表代碼：** PA  
**中文名稱：** 員工基本檔  
**主鍵：** PA01+PA06 (公司別+員工代號)  
**最後更新日期：** 2024-12-19  
**版本：** 1.0

## 資料表說明

員工基本檔(PA)是人力資源管理系統的核心資料表，記錄所有員工的基本資訊，包含個人基本資料、職務資訊、薪資設定、保險資料等。此表提供其他人事相關功能模組的基礎資料，並支援 Trigger 串接 .Net 程式進行資料處理。

**特殊說明：** 此資料表具有 Trigger 串接 .Net 的特性，資料異動時會自動觸發相關程式處理。

## 資料關聯說明

### 資料表間關聯

- 與部門主檔的關聯:
  - PA02 = 部門主檔.部門代號
  - 關聯類型: 多對一 (多位員工歸屬於同一部門)
- 與職等主檔的關聯:
  - PA31 = 職等主檔.職等代號
  - 關聯類型: 多對一 (多位員工可具有相同職等)
- 與職務主檔的關聯:
  - PA32 = 職務主檔.職務代號
  - 關聯類型: 多對一 (多位員工可具有相同職務)

### 參照完整性約束

1. 身份證字號(PA05)必須唯一，不可重複
2. 員工代號(PA06)在同一公司別(PA01)內必須唯一
3. 到職日期(PA20)不可晚於離職日期(PA21)
4. 健保加保日(PA010)應早於或等於健保退保日(PA011)
5. 勞保加保日(PA17)應早於或等於勞保退保日(PA19)

## 資料表管理流程

員工基本檔(PA)是人力資源管理系統的核心資料表，記錄所有員工的基本資訊。新進員工報到時建立基本資料，離職時更新離職日期但不刪除紀錄。資料異動會透過 Trigger 機制串接 .Net 程式進行相關處理，包括薪資計算、保險異動等作業。
