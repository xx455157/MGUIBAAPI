# WK01_年度薪資所得扣繳檔

## 資料表資訊

**系統：** [[ARTHPY]] (薪資系統)  
**資料表代碼：** WK01  
**中文名稱：** 年度薪資所得扣繳檔  
**主鍵：** WK0121 + WK0114 + WK0103  
**最後更新日期：** 2024-01-01  
**版本：** 1.0

## 資料表說明

本資料表用於記錄年度薪資所得扣繳相關資料，包含扣繳單位、所得人資訊、給付金額及扣繳稅額等完整資訊。
