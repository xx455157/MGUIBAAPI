# 代碼參照規則

本文件定義資料表文件中外鍵欄位的標準參照關係，確保系統間代碼參照一致性。**所有資料表文件必須強制遵循本規則**。

## 基本原則與格式規範

| 原則/格式        | 說明                                                 | 範例                                                             |
| ---------------- | ---------------------------------------------------- | ---------------------------------------------------------------- |
| 統一參照原則     | 同類型代碼在所有系統中必須使用相同參照方式           | -                                                                |
| 參照來源唯一性   | 每種代碼類型只有一個標準參照來源                     | -                                                                |
| 絕對參照路徑     | 使用相對於MD根目錄的路徑                             | `../ARTHGUI/A01.md`                                            |
| 連結顯示文字     | 系統名稱-表代碼表中文名稱                            | `ARTHGUI-A01公司基本資料檔`                                    |
| 欄位參照格式     | 表代碼.欄位代碼                                      | `A01.A0101`                                                    |
| 參照說明統一格式 | 欄位中文名稱，參照[系統名稱-表代碼表中文名稱](相對路徑) | `公司代碼，參照[ARTHGUI-A01公司基本資料檔](../ARTHGUI/A01.md)` |

## 標準代碼參照關係

### 1. 通用主檔代碼參照

| 欄位類型   | 參照資料表.欄位             | 關鍵引用規則         |
| ---------- | --------------------------- | -------------------- |
| 公司代碼   | [A01](../ARTHGUI/A01.md).A0101 | 必須存在於A01資料表  |
| 部門代碼   | [A02](../ARTHGUI/A02.md).O001  | 必須與組織結構一致   |
| 員工代號   | [A08](../ARTHPY/A08.md).A0801 | 必須在系統中唯一     |
| 倉庫代碼   | [B13](../ARTHGUI/B13.md).B1301 | 必須與倉儲結構一致   |
| 供應商代碼 | [A16](../ARTHGUI/A16.md).A1601 | 類型必須為「S」      |
| 客戶代碼   | [A16](../ARTHGUI/A16.md).A1601 | 類型必須為「C」      |
| 會計科目   | [A15](../ARTHGUI/A15.md).A1501 | 必須符合科目編碼規則 |

### 2. 系統專用代碼參照

| 欄位類型     | 參照資料表.欄位             | 所屬系統 | 關鍵引用規則           |
| ------------ | --------------------------- | -------- | ---------------------- |
| 發票類別代碼 | SINI.INVOICESET             | ARTHIV   | 必須符合稅務法規       |
| 異動別代碼   | [B30](../ARTHGUI/B30.md).B3001 | ARTHGUI  | 確保業務流程追蹤完整性 |
| 班別代碼     | [AS](../ARTHPY/AS.md).AS01     | ARTHPY   | 必須與排班系統一致     |
| 請假類別代碼 | [AD](../ARTHPY/AD.md).AD01     | ARTHPY   | 必須符合勞動法規       |
| 日別代碼     | SINI.Common_NetPY_DateType  | NETERP   | 必須與行事曆系統一致   |
| 財產類別代碼 | [AE](../ARTHAS/AE.md).AE02 | ARTHAS | 必須存在於AE財產類別設定檔 |

## 檢查與驗證

| 檢查項目     | 檢查方法                     |
| ------------ | ---------------------------- |
| 識別外鍵欄位 | 找出標記為外鍵(F)的欄位      |
| 路徑有效性   | 驗證參照路徑是否存在         |
| 參照一致性   | 確保相同代碼類型使用統一參照 |
| SQL實現檢查  | 確認代碼中正確實現參照關係   |

> **提醒**：所有文件必須以本規範為準，即使原始文件使用不同的參照關係也須修正。
