## 資料表資訊

**系統：** [ARTHAS](../ARTHAS.md) (資產管理系統)
**資料表代碼：** AJ
**中文名稱：** 標的物存放地點檔
**主鍵：** AJ01+AJ02+AJ03+AJ04+AJ05+AJ06+AJ07
**最後更新日期：** 2024-12-19
**版本：** 1.0

## 資料表說明

標的物存放地點檔(AJ)是 ARTHAS 系統中用於記錄資產存放位置資訊的表格，追蹤每個資產的當前存放地點、保管部門、保管人等資訊，為資產管理提供位置追蹤功能。當資產位置發生變更時，系統會在此表中新增一筆記錄，記錄新的存放地點、保管部門、保管人等資訊。

## 資料關聯說明

### 資料表間關聯

- 與資產主檔的關聯:

  - AJ01+AJ02 = 資產主檔.公司別+資產主檔.資產編號
  - 關聯類型: 多對一 (多筆存放記錄對應一個資產)

- 與部門代碼檔的關聯:

  - AJ06 = 部門代碼檔.部門代碼
  - 關聯類型: 多對一 (多筆記錄對應一個部門)

- 與員工主檔的關聯:

  - AJ07 = 員工主檔.員工編號
  - 關聯類型: 多對一 (多筆記錄對應一個員工)

### 參照完整性約束

1. 公司別(AJ01)必須存在於公司基本資料檔中
2. 資產編號(AJ02)必須存在於資產主檔中
3. 保管部門(AJ06)必須存在於部門代碼表中
4. 保管人 ID(AJ07)必須存在於員工主檔中
