# AO_折舊分攤比率格式分配檔

## 資料表資訊

**系統：** [ARTHAS](../ARTHAS.md) (固定資產管理系統)  
**資料表代碼：** AO  
**中文名稱：** 折舊分攤比率格式分配檔  
**主鍵：** AO01+AO02+AO03+AO04  
**最後更新日期：** 2024-07-11  
**版本：** 1.0

## 資料表說明

折舊分攤比率格式分配檔(AO)是工銀訂製的資料表，用於設定固定資產折舊費用在不同單位或部門間的分攤比率格式。

## 欄位定義

> 標記說明：(P) 主鍵欄位、(U) 唯一值欄位、(M) 必填欄位、(F) 外鍵欄位

| 欄位代號 | 欄位名稱    | 資料型態 | 長度 | 屬性 | 備註說明                                             |
| -------- | ----------- | -------- | ---- | ---- | ---------------------------------------------------- |

| AO002    | 建檔時間    | NVARCHAR | 8    | M    | 系統自動產生(HHMMSSFF)                               |
| AO003    | 建檔工作站  | NVARCHAR | 10   |      |                                                      |
| AO004    | 建檔人      | NVARCHAR | 10   |      |                                                      |
| AO005    | 更改日期    | NVARCHAR | 8    |      | YYYYMMDD                                             |
| AO006    | 更改時間    | NVARCHAR | 8    |      | HHMMSSFF                                             |
| AO007    | 更改工作站  | NVARCHAR | 10   |      |                                                      |

## 資料關聯說明

### 資料表間關聯

- 與[AA_固定資產主檔](./AA.md)的關聯:
  - AO02 = AA.AA01 (公司別)
  - AO03 = AA.AA02 (資產編號)
  - 關聯類型: 多對一 (一筆資產可以有多個折舊分攤格式)

- 與[ARTHGUI-A01公司基本資料檔](../ARTHGUI/A01.md)的關聯:
  - AO02 = A01.A0101 (公司別)
  - 關聯類型: 多對一 (多筆折舊分攤記錄對應一個公司)

### 參照完整性約束

1. 新增折舊分攤比率格式時，AO02+AO03組合必須在AA表中存在

## 資料表管理流程

折舊分攤比率格式分配檔(AO)是工銀訂製的功能，用於設定固定資產折舊費用在不同單位或部門間的分攤比率格式。系統會根據此表的設定，將資產的折舊費用按照指定的比率分配到相關單位或部門。
