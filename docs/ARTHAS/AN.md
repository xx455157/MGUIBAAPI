# AN_折舊分攤比率格式設定檔

## 資料表資訊

**系統：** [ARTHAS](../ARTHAS.md) (固定資產管理系統)  
**資料表代碼：** AN  
**中文名稱：** 折舊分攤比率格式設定檔  
**主鍵：** AN01+AN02  
**最後更新日期：** 2024-07-11  
**版本：** 1.0

## 資料表說明

折舊分攤比率格式設定檔(AN)是工銀訂製的資料表，用於設定各部門在折舊分攤格式中的比率，配合AO表使用，實現固定資產折舊費用在不同部門間的分攤。

## 欄位定義

> 標記說明：(P) 主鍵欄位、(U) 唯一值欄位、(M) 必填欄位、(F) 外鍵欄位

| 欄位代號 | 欄位名稱    | 資料型態 | 長度 | 屬性 | 備註說明                 |
| -------- | ----------- | -------- | ---- | ---- | ------------------------ |

| AN002    | 建檔時間    | NVARCHAR | 8    | M    | 系統自動產生(HHMMSSFF)   |
| AN003    | 建檔工作站  | NVARCHAR | 10   |      |                          |
| AN004    | 建檔人      | NVARCHAR | 10   |      |                          |
| AN005    | 更改日期    | NVARCHAR | 8    |      | YYYYMMDD                 |
| AN006    | 更改時間    | NVARCHAR | 8    |      | HHMMSSFF                 |
| AN007    | 更改工作站  | NVARCHAR | 10   |      |                          |
| AN008    | 更改人      | NVARCHAR | 10   |      |                          |

## 資料關聯說明

### 資料表間關聯

- 與[AO_折舊分攤比率格式分配檔](./AO.md)的關聯:
  - AN01 = AO.AO01 (格式ID)
  - 關聯類型: 多對一 (一個折舊分攤格式對應多個部門比率設定)

### 參照完整性約束

1. 新增部門比率設定時，總和應為100%
2. AN01格式ID必須在AO表中存在

## 資料表管理流程

折舊分攤比率格式設定檔(AN)配合AO表使用，用於設定各部門在折舊分攤格式中的比率。系統會根據此表的設定，計算各部門應分攤的折舊費用金額。設定時應確保各部門比率合計為100%，以確保折舊費用能完全分攤。
