## 資料表資訊

**系統：** [ARTHAS](../ARTHAS.md) (固定資產管理系統)
**資料表代碼：** AC
**中文名稱：** 財產異動主檔
**主鍵：** AC01+AC02+AC03+AC04+AC05+AC07+AC08
**最後更新日期：** 2024-07-11
**版本：** 1.0

## 資料表說明

財產異動主檔(AC)用於記錄固定資產的各種異動情況，包括購入、增值、報廢、出售、折舊、維修等。此表記錄了所有對固定資產所進行的操作及其相關資訊。

## 資料關聯說明

### 資料表間關聯

- 與[AA_固定資產主檔](./AA.md)的關聯:

  - AC01 = AA.AA01 (公司別)
  - AC07 = AA.AA02 (資產編號)
  - 關聯類型: 多對一 (多筆異動記錄對應一筆資產記錄)
- 與[ARTHGUI-A01公司基本資料檔](../ARTHGUI/A01.md)的關聯:

  - AC01 = A01.A0101 (公司別)
  - 關聯類型: 多對一 (多筆異動記錄對應一個公司)

### 參照完整性約束

1. 新增異動記錄時，AC01+AC07組合必須在AA表中存在
2. 異動記錄的單據日期(AC06)不應早於資產取得日期(AC08)

## 資料表管理流程

財產異動主檔(AC)是ARTHAS系統的重要資料表，記錄公司所有固定資產的異動情況。透過異動別(AC03)區分不同的異動類型，並記錄相關金額、日期等資訊。系統會根據異動記錄自動更新固定資產主檔(AA)中的相關資訊。
