# AE_財產類別設定檔

## 資料表資訊

**系統：** [ARTHAS](../ARTHAS.md) (固定資產管理系統)  
**資料表代碼：** AE  
**中文名稱：** 財產類別設定檔  
**主鍵：** AE01 + AE02  
**最後更新日期：** 2024-07-11  
**版本：** 1.1

## 資料表說明

財產類別設定檔(AE)用於記錄各公司財產類別的編碼規則與相關會計科目設定。  
AE02於S011016008變更為7碼：「財產類別4碼+年2碼+月1碼」，原為「財產類別4碼+年2碼」。
