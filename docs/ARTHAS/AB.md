# AB_財產分佈檔

## 資料表資訊

**系統：** [ARTHAS](../ARTHAS.md) (固定資產系統)
**資料表代碼：** AB
**中文名稱：** 財產分佈檔
**主鍵：** AB01+AB02+AB03+AB04+AB05+AB06+AB07
**最後更新日期：** 2024-07-05
**版本：** 1.0

## 資料表說明

財產分佈檔用於記錄公司固定資產的分佈情況，包含資產的位置、保管部門、保管人及使用狀態等資訊。
