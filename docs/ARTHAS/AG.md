# AG_單據自動編號序號檔

## 資料表資訊

**系統：** [ARTHAS](../ARTHAS.md) (固定資產管理系統)  
**資料表代碼：** AG  
**中文名稱：** 單據自動編號序號檔  
**主鍵：** AG01 + AG02 + AG03  
**最後更新日期：** 2026-05-21  
**版本：** 1.0

## 資料表說明

單據自動編號序號檔(AG)用於記錄各公司、各字軌、各日期的單據目前序號。此表由單據編號自動設定檔(AF)驅動，於電腦自動編號時遞增序號以產生單據號碼。

## 資料關聯說明

### 資料表間關聯

- 與[AF_單據編號自動設定檔](./AF.md)的關聯:

  - AG01 = AF.AF01 (公司別)
  - AG02 = AF.AF02 (字軌)
  - 關聯類型: 多對一 (多筆序號記錄對應一筆編號設定)

- 與[ARTHGUI-A01公司基本資料檔](../ARTHGUI/A01.md)的關聯:

  - AG01 = A01.A0101 (公司別)
  - 關聯類型: 多對一 (多筆序號記錄對應一個公司)

### 參照完整性約束

1. 新增序號記錄時，AG01、AG02須對應AF表中已存在的公司別與字軌設定
2. AG01公司別必須在A01表中存在
3. 產生新單據編號時，AG04目前序號須遞增並寫回此表
