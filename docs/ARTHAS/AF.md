# AF_單據編號自動設定檔

## 資料表資訊

**系統：** [ARTHAS](../ARTHAS.md) (固定資產管理系統)  
**資料表代碼：** AF  
**中文名稱：** 單據編號自動設定檔  
**主鍵：** AF01 + AF02  
**最後更新日期：** 2026-05-21  
**版本：** 1.0

## 資料表說明

單據編號自動設定檔(AF)用於設定各公司、各字軌的單據編號產生規則，包含異動別、編號原則及類別等參數。此表與單據自動編號序號檔(AG)搭配使用，作為固定資產系統自動編號模組的設定主檔。

## 資料關聯說明

### 資料表間關聯

- 與[AG_單據自動編號序號檔](./AG.md)的關聯:

  - AF01 = AG.AG01 (公司別)
  - AF02 = AG.AG02 (字軌)
  - 關聯類型: 一對多 (一筆編號設定可對應多筆序號記錄)

- 與[ARTHGUI-A01公司基本資料檔](../ARTHGUI/A01.md)的關聯:

  - AF01 = A01.A0101 (公司別)
  - 關聯類型: 多對一 (多筆設定記錄對應一個公司)

### 參照完整性約束

1. 新增設定記錄時，AF01公司別必須在A01表中存在
2. 編號原則(AF04)為電腦自動編號時，須搭配AG表維護目前序號
