## 資料表資訊

**資料表代碼：** AA
**中文名稱：** 固定資產主檔
**主鍵：** AA01 + AA02
**最後更新日期：** 2024-07-11
**版本：** 1.0

## 資料表說明

固定資產主檔(AA)用於記錄公司所有固定資產的基本資料，包括取得日期、金額、折舊資訊等。此表是固定資產管理系統的核心資料表，記錄固定資產的完整生命週期資訊。

## 資產屬性代碼說明

| 代碼 | 說明     | 詳細說明                 |
| ---- | -------- | ------------------------ |
| Y    | 折舊性   | 需要計提折舊的資產       |
| N    | 列管性   | 不計提折舊但需列管的資產 |
| L    | 非折舊性 | 不計提折舊的資產         |
| S    | 攤提性   | 需要按月攤提的資產       |

## 資料關聯說明

### 資料表間關聯

- 與[AB_固定資產異動檔](./AB.md)的關聯:

  - AA01 = AB.AB01 (公司別)
  - AA02 = AB.AB02 (資產編號)
  - 關聯類型: 一對多 (一筆資產可以有多筆異動記錄)
- 與[ARTHGUI-A01公司基本資料檔](../ARTHGUI/A01.md)的關聯:

  - AA01 = A01.A0101 (公司別)
  - 關聯類型: 多對一 (多筆資產記錄對應一個公司)

### 參照完整性約束

1. 新增資產記錄時，AA01公司別必須在A01表中存在
2. 異動資產時，若有折舊相關變更，須同步更新AB表

## 資料表管理流程

固定資產主檔(AA)是ARTHAS系統的核心資料表，記錄公司各項固定資產的基本資料。資產生命週期從取得開始，經過使用、折舊，直到報廢處分，所有過程都需在此資料表中有完整記錄。
