# AH_導入財產備份檔

## 資料表資訊

**系統：** [ARTHAS](../ARTHAS.md) (固定資產管理系統)  
**資料表代碼：** AH  
**中文名稱：** 導入財產備份檔  
**主鍵：** AH01 + AH02 + AH03  
**最後更新日期：** 2026-05-21  
**版本：** 1.0

## 資料表說明

導入財產備份檔(AH)用於儲存固定資產資料導入作業時的備份內容，欄位結構與[AA_固定資產主檔](./AA.md)相近，並額外記錄導入日期與導入單號。**此表已不再使用**，僅供歷史資料查閱與對照，現行作業請使用 AA 表。

## 資料關聯說明

### 資料表間關聯

- 與[AA_固定資產主檔](./AA.md)的關聯:

  - AH01 = AA.AA01 (公司別)
  - AH02 = AA.AA02 (資產編號)
  - 關聯類型: 備份對照 (導入備份與正式主檔欄位結構相近，主鍵組成不同)

- 與[ARTHGUI-A01公司基本資料檔](../ARTHGUI/A01.md)的關聯:

  - AH01 = A01.A0101 (公司別)
  - 關聯類型: 多對一

### 參照完整性約束

1. 此表已停用，新系統不應再寫入資料
2. 歷史資料中 AH01 公司別應對應 A01 表中的有效公司代碼
