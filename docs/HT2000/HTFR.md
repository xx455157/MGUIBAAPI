# HTFR - 食譜主檔

## 資料表說明
本資料表用於記錄飯店食譜相關資訊，包含食譜基本資料、材料明細、成本計算等資訊。

### 索引定義

| 索引名稱 | 索引類型 | 索引欄位 | 備註 |
|---------|---------|---------|------|
| PK_HTFR | PRIMARY KEY | FR01, FR02 | 主鍵索引 |

### 資料關聯說明

1. FR02 (材料號碼) 關聯至庫存主檔 (ITEM)
2. FR13 (報價廠商) 關聯至廠商主檔 (SUPPLIER)
3. FR15 (庫存公司別) 關聯至公司主檔 (COMPANY)

## 資料維護說明

1. 新增食譜時，系統自動產生建檔相關欄位 (FR001-FR004)
2. 修改資料時，系統自動更新異動相關欄位 (FR005-FR008)
3. 成本相關欄位 (FR10, FR12, FR19) 由系統自動計算
4. 材料來源 (FR17) 決定材料號碼 (FR02) 的參照來源

## 使用注意事項

1. 食譜代碼 (FR01) 必須唯一
2. 同一食譜下的材料號碼 (FR02) 不可重複
3. 成本參加月份 (FR11) 必須符合 YYYYMM 格式
4. 所有日期欄位必須符合 YYYYMMDD 格式
