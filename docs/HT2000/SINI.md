# SINI - 系統參數資料表

## 基本資訊

- **系統名稱**：[[HT2000]] 
- **資料表代碼**：SINI
- **資料表名稱**：系統參數資料表
- **主鍵**：Section、Topic、Language
- **版本**：1.0
- **最後更新**：2022/07/25

## 資料表說明

本資料表用於儲存系統參數設定，包含各區段(Section)的主題(Topic)及其對應值。

## 欄位定義

| 欄位代號   | 欄位名稱   | 資料型態 | 長度 | 備註     |
| ---------- | ---------- | -------- | ---- | -------- |
| P1         | Section    | NVARCHAR | 2    | 區段代碼 |
| P2         | Topic      | NVARCHAR | 140  | 主題名稱 |
| TopicValue | TOPICVALUE | NVARCHAR | MAX  | 參數值   |
| P3         | Language   | NVARCHAR | 10   | 語言代碼 |

## 索引定義

- 主鍵索引：Section、Topic、Language
