■ 重要說明

1. OA20 / OA21 為正式既有資料表，不可重新建表，只能用 ALTER TABLE ADD 補欄位。
2. OA22 為新增草案，尚未正式確認建表。OA23~OA25 草案已棄用。
3. OA22 為收支明細表，同一筆資料（同一序號）同時包含收支預算、發票、收款狀態。
4. 收支款現況（OA25）不再獨立存表，改由 OA22 即時統計計算。
5. 所有資料表均建議使用統一的 NetOA 命名風格建檔/異動欄位。
6. API DTO 欄位名稱已與前端 payload 對應，詳細對照請見各別文件。
7. SQL 建表腳本請見 NetOA欄位說明-OA22.md 中的「建表 SQL」章節。
