# CINI_國際化參數設定檔

## 資料表資訊

**系統：** [NETERP](../../NETERP.md) (企業資源規劃系統)
**子系統：** [NETGUI](../NETGUI.md) (系統界面模組)
**資料表代碼：** CINI
**中文名稱：** 國際化參數設定檔
**主鍵：** Comp+CSection+CTopic+CLanguage
**最後更新日期：** 2024-07-11
**版本：** 1.0

## 資料表說明

國際化參數設定檔(CINI)用於儲存系統中多語言介面設定和顯示文字，支援不同語言的系統界面顯示，是系統國際化的核心資料表。

## 欄位定義

> 標記說明：(P) 主鍵欄位、(U) 唯一值欄位、(M) 必填欄位、(F) 外鍵欄位

| 欄位代號    | 欄位名稱 | 資料型態 | 長度 | 屬性 | 備註說明                    |
| ----------- | -------- | -------- | ---- | ---- | --------------------------- |
| Comp        | 公司別   | NVARCHAR | 10   | P,M  | 公司代碼                    |
| CSection    | 區段名稱 | NVARCHAR | 255  | P,M  | Section Name                |
| CTopic      | 主題     | NVARCHAR | 140  | P,M  | Topic                       |
| CLanguage   | 語言     | NVARCHAR | 10   | P,M  | 語言代碼(zh-tw/en/zh-cn/…) |
| CTopicValue | 主題內容 | NVARCHAR | MAX  | M    | Topic Value                 |

## 語言代碼說明

| ja    | 日文     | 日語               |

## 常用代碼設定說明

### 日別代碼 (Common_NetPY_Holiday_DayCode)

此區段用於定義人力資源及薪資管理系統中的休假日別代碼。

| Comp | CSection                     | CTopic | CLanguage | CTopicValue | 說明     |
| ---- | ---------------------------- | ------ | --------- | ----------- | -------- |
|      | Common_NetPY_Holiday_DayCode | 休     |           | C           | 休假日   |
|      | Common_NetPY_Holiday_DayCode | 例     |           | D           | 例假日   |
|      | Common_NetPY_Holiday_DayCode | 國     |           | B           | 國定假日 |

備註：系統在處理請假/出缺勤資料時，會依據此代碼判斷休假類型。

## 索引定義

## 資料關聯說明

### 參照完整性約束

1. Comp(公司別)必須是有效的公司代碼
2. CLanguage(語言)必須是系統支援的語言代碼

## 資料表管理流程

國際化參數設定檔(CINI)是NETGUI系統界面模組的重要資料表，用於管理系統中所有需要多語言顯示的文字資源。系統根據使用者選擇的語言設定，從此表中檢索對應的文字內容，實現系統介面的多語言顯示。管理人員可透過此表新增或修改系統中各種語言的介面文字，無需修改程式即可實現系統的國際化。
