# SINI_系統參數設定檔

## 資料表資訊

**系統：** [NETERP](../../NETERP.md) (企業資源規劃系統)
**子系統：** [NETGUI](../NETGUI.md) (系統界面模組)
**資料表代碼：** SINI
**中文名稱：** 系統參數設定檔
**主鍵：** SECTION+TOPIC+LANGUAGE
**最後更新日期：** 2024-07-11
**版本：** 1.1

## 資料表說明

系統參數設定檔(SINI)用於儲存系統全域性參數設定，包括系統預設值、功能開關、常用代碼等，是系統配置的核心資料表。與CINI(國際化參數設定檔)不同，SINI主要用於系統功能相關的參數設定，而非僅用於多語言顯示。

## 欄位定義

> 標記說明：(P) 主鍵欄位、(U) 唯一值欄位、(M) 必填欄位、(F) 外鍵欄位

| 欄位代號   | 欄位名稱 | 資料型態 | 長度 | 屬性 | 備註說明                    |
| ---------- | -------- | -------- | ---- | ---- | --------------------------- |
| SECTION    | 區段名稱 | NVARCHAR | 300  | P,M  | Section Name                |
| TOPIC      | 主題     | NVARCHAR | 140  | P,M  | Topic                       |
| LANGUAGE   | 語言     | NVARCHAR | 10   | P,M  | 語言代碼(zh-tw/en/zh-cn/…) |
| TOPICVALUE | 主題內容 | NVARCHAR | MAX  | M    | Topic Value                 |

## 常用參數區段說明

| 區段名稱 (SECTION)              | 說明             | 用途                                       |
| ------------------------------- | ---------------- | ------------------------------------------ |
| System_Config                   | 系統基本設定     | 存放系統基本運行參數                       |
| Common_NetPY_LeaveApproveStatus | 請假簽核狀態代碼 | 用於DW表的簽核狀態欄位                     |
| Common_NetPY_LeaveApproveResult | 請假核准結果代碼 | 用於DW表的核准結果欄位                     |

| Default_Value                   | 系統預設值       | 各模組預設值設定                           |
| Function_Flag                   | 功能開關         | 控制系統特定功能的啟用狀態                 |
| Email_Template                  | 郵件範本         | 系統通知郵件的內容範本                     |

## 日別代碼說明

> 區段：Common_NetPY_DateType

| 代碼 | 中文名稱 | 英文名稱       | 說明                       |
| ---- | -------- | -------------- | -------------------------- |
| B    | 國定假日 | Holiday        | 國家法定假日               |
| C    | 休息日   | Restday        | 正常班表中的休息日         |
| D    | 例假日   | RoutineHoliday | 每週固定的休假日，如週六日 |
| Z    | 特別休假 | Annual leave   | 年度特別休假               |

> 此日別代碼用於排班系統與請假管理系統，判斷日期類型及計算加班費用。

## 資料關聯說明

### 參照完整性約束

1. LANGUAGE(語言)必須是系統支援的語言代碼或空值

## 資料表管理流程

系統參數設定檔(SINI)是NETGUI系統界面模組的核心資料表，用於管理系統中各種全域性的參數設定。系統在啟動和運行過程中，會從此表中讀取各種配置參數，以控制系統的行為和功能。管理人員可透過此表調整系統的各項參數，實現功能的靈活配置，無需修改程式碼即可改變系統行為。
