## 資料表說明

請假申請主檔(DW)用於記錄員工請假申請的主要資訊，包括請假日期、時間、原因、簽核流程等，作為員工出勤和請假管理的基礎資料。

## 資料關聯說明

### 資料表間關聯

- 與[PA_員工基本資料檔](../PA.md)的關聯:
  - DW03 = PA.PA05 (身分證編號)
  - DW01+DW04 = PA.PA01+PA.PA06 (公司別+員工編號)
  - DW61+DW09 = PA.PA01+PA.PA06 (代理人公司別+代理人編號)
  - 關聯類型: 多對一 (多筆請假記錄對應一個員工)

- 與[AB_假別代碼檔](../AB.md)的關聯:
  - DW05 = AB.AB03 (請假代號)
  - DW15 = AB.AB03 (扣抵假別)
  - 關聯類型: 多對一 (多筆請假記錄對應一個假別)

- 與[AT_簽核流程檔](../AT.md)的關聯:
  - DW01+DW10 = AT.AT01+AT.AT02 (公司別+流程編號)
  - 關聯類型: 多對一 (多筆請假記錄對應一個簽核流程)

- 與[DWA_請假申請明細檔](./DWA.md)的關聯:
  - DW01+DW02 = DWA.DWA01+DWA.DWA02 (公司別+請假單號)
  - 關聯類型: 一對多 (一筆請假主檔對應多筆請假明細)

### 參照完整性約束

1. 新增請假申請時，DW01+DW04組合必須在PA表中存在
2. 請假代號(DW05)必須在AB表中存在
3. 代理人編號(DW09)必須是有效的員工編號

## 資料表管理流程

請假申請主檔(DW)是NetPY薪資管理系統的重要資料表，用於記錄員工的請假申請資訊。當員工提出請假申請時，系統會建立一筆請假主檔記錄，並透過簽核流程進行審核。此表與請假申請明細檔(DWA)密切關聯，主檔記錄請假的基本資訊，明細檔則記錄每天的請假詳細資料。
