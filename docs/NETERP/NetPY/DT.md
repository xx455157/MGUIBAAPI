# DT_薪資差假申請流程設定檔

## 資料表資訊

**系統：** NETERP/NETPY (NetERP薪資管理系統)
**資料表代碼：** DT
**中文名稱：** 薪資差假申請流程設定檔
**主鍵：** DT01 + DT02 (公司別 + 流程編號)
**最後更新日期：** 2024-07-17
**版本：** 1.0

## 資料表說明

本資料表用於設定薪資系統中各種差假申請流程，包括不同公司、部門的請假審批流程定義。系統根據此表的設定來執行相應的差假審批流程，確保符合公司的請假管理規範。

## 資料關聯說明

### 資料表間關聯

- 與公司基本資料檔(A01)的關聯:

  - DT01 = A01.A0101
  - 關聯類型: 多對一 (多個流程對應一個公司)
- 與部門基本資料檔(A02)的關聯:

  - DT03 = A02.O001
  - 關聯類型: 多對一 (多個流程對應一個部門)
- 與假別主檔(AD)的關聯:

  - DT04 = AD.AD01
  - 關聯類型: 多對一 (多個流程對應一個假別)

### 參照完整性約束

1. 公司別(DT01)必須存在於公司基本資料檔(A01)中
2. 部門別(DT03)必須存在於部門基本資料檔(A02)中
3. 差假代號(DT04)必須存在於假別主檔(AD)中

## 資料表管理流程

DT資料表是NetERP薪資管理系統中差假申請流程的核心設定表，用於定義各公司、部門的差假申請流程。系統管理員可通過維護該表配置不同類型假別的審批流程。當員工提交差假申請時，系統會根據此表設定的流程執行相應的審批程序。表中定義的流程會決定請假申請的審批路徑、審批人員及通知機制。
