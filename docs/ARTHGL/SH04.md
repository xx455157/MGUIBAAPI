# SH04\_損益部門設定檔

## 資料表資訊

**系統：** [ARTHGL](../ARTHGL.md) (總帳系統)
**資料表代碼：** SH04
**中文名稱：** 損益部門設定檔
**主鍵：** SH0401
**最後更新日期：** 2024-12-19
**版本：** 1.0

## 資料表說明

損益部門設定檔用於定義損益報表的部門別設定，主要用於 GLR99 報表系統。此表記錄了各損益報表的活頁名稱、對應的部門別、表頭名稱、套用母版及報表順序等資訊，支援多部門選擇功能。

## 資料關聯說明

### 資料表間關聯

- 與報表母版檔的關聯:
  - SH0404 = 母版檔.母版代碼
  - 關聯類型: 多對一 (一個母版可對應多個損益部門設定)

### 參照完整性約束

1. 套用母版(SH0404)必須存在於報表母版檔中
2. 建檔人(SH04004)必須存在於人員基本資料檔中
3. 更改人(SH04008)必須存在於人員基本資料檔中
