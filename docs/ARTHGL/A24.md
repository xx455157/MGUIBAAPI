## 資料表說明

`<a id="table-description"></a>`

傳票(製票)資料表(A24)用於儲存總帳系統中的傳票與製票資料，包含借貸金額、對沖資訊、簽核狀態等。此表為總帳系統的核心資料表，記錄所有會計交易的傳票明細。

## 資料關聯說明

`<a id="data-relations"></a>`

### 資料表間關聯

- 與公司基本資料檔(A01)的關聯:
  - A2401 = A0101 (公司別)
  - 關聯類型: 多對一 (一個公司可以有多筆傳票)
- 與會計科目資料表(A15)的關聯:
  - A2401 = A1501 (公司別)
  - A2405 = A1502 (科目代號)
  - A2406 = A1503 (子目代號)
  - 關聯類型: 多對一 (一個會計科目可用於多筆傳票明細)
- 與部門資料表的關聯:
  - A2407 = 部門代碼
  - 關聯類型: 多對一 (一個部門可以有多筆傳票明細)

### 參照完整性約束

1. 公司別(A2401)必須存在於公司基本資料檔(A01)中
2. 科目與子目組合(A2405, A2406)必須存在於會計科目資料表(A15)中
3. 資料型態為傳票時，必須有對應的製票記錄存在

## 資料表特性說明

`<a id="table-properties"></a>`

傳票(製票)資料表具有以下特性：

1. 每筆傳票都有多筆明細，流水號必須唯一
2. 每筆傳票的借貸方金額必須平衡
3. 過帳後的傳票不允許修改
4. 傳票可來自不同系統模組，具有統一的格式標準
5. 租賃業務有特殊的欄位使用方式

## 資料表管理流程

`<a id="management-process"></a>`

傳票(製票)資料表(A24)是總帳系統的核心資料表，記錄所有會計交易資訊。傳票的處理流程通常為：建立製票資料 → 核准轉為傳票 → 過帳處理 → 結算報表產生。

系統管理員需定期檢查未過帳傳票，並對長期未處理的資料進行清理或封存，以確保系統效能。
