# A33_會計科目每日異動總表與預算檔

## 資料表資訊

**系統：** ARTHGL (總帳系統)
**資料表代碼：** A33
**中文名稱：** 會計科目每日異動總表與預算檔
**主鍵：** A3301 + A3302 + A3303 + A3304 + A3305 + A3306 + A3307
**最後更新日期：** 2024-07-17
**版本：** 1.0

## 資料表說明

本資料表用於記錄會計科目每日的借貸異動、預算金額及相關統計資訊，依公司、科目、子目、年度、月份、日期、部門等多重主鍵組合，支援會計報表、預算控管與分析。
