**中文名稱：** 部門別資料表
**主鍵：** A0201
**最後更新日期：** 2024-12-19
**版本：** 1.0

## 資料表說明

部門別資料表為金旭共用系統的核心資料表，用於儲存公司內所有部門的基本資訊。此表包含部門的中英文名稱、負責人、地址、連絡方式等完整資訊，並支援多國語言顯示。此表與 .NET Trigger 機制整合，確保資料一致性與完整性。

## 資料關聯說明

### 資料表間關聯

- 與公司基本資料檔(A01)的關聯:
  - A0220 = A01.A0101
  - 關聯類型: 多對一 (多個部門可歸屬於同一公司)
- 與部門層級資料檔(A02A)的關聯:
  - A0201 = A02A.A02A01
  - 關聯類型: 一對一 (一個部門對應一個層級資料)

### 參照完整性約束

1. 歸屬公司別(A0220)必須存在於公司基本資料檔(A01)中
2. 建檔人(A02004)必須存在於人員基本資料檔中
3. 更改人(A02008)必須存在於人員基本資料檔中
4. 類別(A0224)必須存在於類別代碼表(TB04)中

## 特殊說明

- 此表與 .NET Trigger 機制整合，確保資料一致性
- 部門層級(A0221)參照 INI 設定檔，Section='DeptLevel', topic=A0221
- 類別(A0224)參照 HTTB=POSTYPE TB04 類別代碼表
- 門市相關欄位(A0230, A0234, A0236)用於門市管理功能
