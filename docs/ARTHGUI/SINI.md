# SINI_系統環境參數設定檔

`<a id="top"></a>`

## 資料表資訊

`<a id="table-info"></a>`

**系統：** ARTHGUI (通用管理系統)
**資料表代碼：** SINI
**中文名稱：** 系統環境參數設定檔
**主鍵：** SECTION, TOPIC
**最後更新日期：** 2024-05-28
**版本：** 1.1

## 資料表說明

`<a id="table-description"></a>`

系統環境參數設定檔(SINI)用於儲存ARTHGUI系統的各種環境參數設定，包括系統運行參數、顯示設定、預設值等。此表為系統配置的核心資料表，提供各模組所需的參數配置資訊。

## 欄位定義

`<a id="field-definitions"></a>`

> 標記說明：(P) 主鍵欄位、(U) 唯一值欄位、(M) 必填欄位、(F) 外鍵欄位

| ---------- | ---------- | -------- | ---- | ---- | ---------------- |

## 傳票格式代碼設定 (SlipType)

`<a id="sliptype"></a>`

傳票格式代碼區段(SECTION='SlipType')定義系統中使用的各種傳票格式類型：

| 主題代碼(TOPIC) | 參數值(TOPICVALUE) | 說明                   |
| --------------- | ------------------ | ---------------------- |
| type1           | 轉帳傳票           | 一般的轉帳用途傳票     |
| type2           | 應收帳款           | 用於應收帳款業務的傳票 |
| type3           | 應付帳款           | 用於應付帳款業務的傳票 |
| type4           | 應收票據           | 用於應收票據業務的傳票 |
| type5           | 應付票據           | 用於應付票據業務的傳票 |
| type6           | 銀行存款           | 用於銀行存款業務的傳票 |
| type7           | 客戶貨款           | 用於客戶貨款業務的傳票 |
| type8           | 採購貨款           | 用於採購貨款業務的傳票 |

## 資料關聯說明

`<a id="data-relations"></a>`

### 資料表間關聯

系統環境參數設定檔(SINI)為獨立的設定表，主要被其他模組參照使用：

- 會計科目資料表(A15)的傳票格式代碼(A1512)參照SINI的SlipType區段
- 其他系統模組參照SINI表中對應的參數設定

### 參照完整性約束

1. SECTION和TOPIC的組合必須是唯一的
2. 系統模組參照SINI表時應檢查參數是否存在，若不存在應使用預設值

## 資料表管理流程

`<a id="management-process"></a>`

系統環境參數設定檔(SINI)是ARTHGUI系統的核心配置資料表，管理系統各模組的運行參數。系統管理員負責維護此表，遵循以下原則：

1. 參數修改應記錄在系統日誌中
2. 系統參數更改應在非峰值時段進行
3. 關鍵參數更改前應進行備份
4. 定期檢查參數配置確保系統最佳效能
