# A21\_客戶常用送貨地址資料表

## 資料表資訊

**系統：** [ARTHGUI](../ARTHGUI.md) (金旭共用系統)
**資料表代碼：** A21
**中文名稱：** 客戶常用送貨地址資料表
**主鍵：** A2101+A2102+A2103+A2104
**最後更新日期：** 2024-12-19
**版本：** 1.0

## 資料表說明

此資料表主要用於儲存客戶的常用送貨地址資訊，包含收貨人資料、地址資訊、發票相關資訊等。支援多個地址欄位，可儲存完整的地址資訊，並針對羅昇訂單發料有特殊處理邏輯。

## 資料關聯說明

### 資料表間關聯

- 與客戶主檔的關聯:
  - A2103 = 客戶編號
  - 關聯類型: 多對一 (一個客戶可有多筆送貨地址)

### 參照完整性約束

1. 公司別(A2101)必須存在於公司基本資料檔中
2. 客戶編號(A2103)必須存在於客戶主檔中
