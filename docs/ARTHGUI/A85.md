## 資料表說明

位置紀錄檔(A85)用於記錄系統中各種位置相關資訊，包括 IP 地址、GPS 座標、部門代碼等。此表支援行動辦公室 Wifi 打卡模式，可記錄員工打卡位置的地理資訊，是出勤管理系統的重要組成部分。

## 資料關聯說明

### 主鍵組合

主鍵：A8501 (P)

### 資料表間關聯

- 與[AQ\_刷卡記錄檔](../ARTHPY/AQ.md)的關聯:
  - A8502 = AQ.AQ20 (位置描述)
  - A8503 = AQ.AQ15 (緯度)
  - A8504 = AQ.AQ16 (經度)
  - 關聯類型: 一對多 (一個位置記錄對應多筆刷卡記錄)

### 參照完整性約束

1. A8502(IP 地址)與 A8503、A8504(GPS 座標)為互斥關係
2. A8505(部門代碼)必須參照有效的部門代碼表
3. A8530 為\*時，表示該 IP 地址用於打卡功能
