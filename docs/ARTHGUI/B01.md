# B01_單據編號設定檔

## 資料表資訊

**系統：** [ARTHGUI](../ARTHGUI.md) (金旭共用系統)
**資料表代碼：** B01
**中文名稱：** 單據編號設定檔
**主鍵：** B0101 + B0102
**最後更新日期：** 2025-04-29
**版本：** 1.0

## 資料表說明

單據編號設定檔(B01)用於管理各公司、字軌、異動別的單據編號規則，包含人工/電腦編號原則、類別等設定。主要供單據產生與管理流程參照。

## 資料關聯說明

### 資料表間關聯

- 與[A01_公司基本資料檔](./A01.md)的關聯：
  - B0101 = A01.A0101 (公司別)
  - 關聯類型：多對一
- 與[B30_異動原因檔](./B30.md)的關聯：
  - B0103 = B30.B3001 (異動別)
  - 關聯類型：多對一

### 參照完整性約束

1. 公司別(B0101)必須存在於公司基本資料檔(A01)中
2. 異動別(B0103)必須為有效異動別代碼(B30)

## 組合鍵說明

- B01: B0101 + B0102
- B: B0101 + B0103
